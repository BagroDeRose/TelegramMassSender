## Русский

### Предпросмотр совпадает с отправкой
- Раньше предпросмотр показывал длинный текст и фото одним сообщением с подписью, а при отправке текст уходил отдельным сообщением. Теперь предпросмотр и отправка строятся по одному и тому же плану: предпросмотр показывает ровно те сообщения, которые уйдут, в том же порядке.
- Лимит подписи берётся для вашего аккаунта у самого Telegram: для обычного аккаунта 1 024 символа, у Premium больше. Если узнать его не удалось — 1 024. Символы считаются так же, как в Telegram (эмодзи может занимать два).
- Если текст длиннее подписи, в карточке «Сообщение» и в редакторе появляется предупреждение, например: «Текст длиннее подписи к фото (1 487 из 1 024) — фото и текст уйдут двумя сообщениями». Счётчик символов в редакторе при вложениях показывает лимит подписи.
- Для этого случая можно выбрать порядок: «Сначала текст, потом фото» (как раньше) или «Сначала фото, потом текст». Выбор сохраняется в шаблоне.
- Если в тексте есть `{name}`, длина считается с примером имени. Если с длинным именем получателя текст может не поместиться, программа подскажет.
- Файлы, которые Telegram отправляет отдельными сообщениями (например, документ рядом с альбомом), в предпросмотре теперь тоже отдельные сообщения.

### Превью ссылок
- **Изменение поведения:** раньше Telegram сам строил превью для первой ссылки в тексте. Теперь превью по умолчанию **выключено** — при рассылке сообщение выглядит одинаково у всех. Старые шаблоны открываются с выключенным превью.
- Блок «Превью ссылки» в карточке «Сообщение» и в редакторе (виден, когда в тексте есть ссылки): для одной ссылки — переключатель, для нескольких — выбор ссылки (обычные адреса и ссылки под текстом, в том числе `t.me`), положение над текстом или под ним, крупное или мелкое изображение.
- В подписи к фото превью ссылок не показываются — тогда блок неактивен и объясняет почему.
- Предпросмотр показывает карточку превью там, где она будет: с заголовком и описанием страницы, если аккаунт подключён, иначе — с доменом.
- Настройки превью и порядка сохраняются в шаблоне, работают в Мастере кампании и при «Повторить ошибки».

## English

### The preview matches what is sent
- The preview used to show a long text and a photo as one captioned message while the send split them. Now the preview and the send use the same plan: the preview shows exactly the messages that will go out, in the same order.
- The caption limit is your account's, as Telegram reports it: 1,024 characters for a regular account, more with Premium; 1,024 if it can't be read. Characters are counted the way Telegram counts them (an emoji may take two).
- When the text is longer than a caption, the Message card and the editor say so, for example: "The text is longer than a photo caption (1,487 of 1,024) — the photo and the text will go as two messages". With attachments, the editor's character counter shows the caption limit.
- For that case you can choose the order: "Text first, then the photo" (as before) or "Photo first, then the text". The choice is saved with a template.
- With `{name}` in the text, the length is counted with the example name, and you get a hint when a long recipient name could push it over.
- Files that Telegram sends as separate messages (for example a document next to an album) are now separate messages in the preview too.

### Link previews
- **Behaviour change:** Telegram used to build a preview for the first link on its own. Previews are now **off** by default, so a mass send looks the same for everyone. Templates saved earlier open with the preview off.
- A "Link preview" block in the Message card and the editor (shown when the text has links): a switch for one link, a choice of link for several (plain addresses and links under text, `t.me` included), above or below the text, large or small image.
- Telegram shows no link previews in a photo caption; in that case the block is disabled and says why.
- The preview shows the card where it will be: with the page title and description when the account is connected, otherwise with the domain.
- Preview and order settings are saved with a template and work in the Campaign Wizard and for "Retry failures".
