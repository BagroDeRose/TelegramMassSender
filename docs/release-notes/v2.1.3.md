# Telegram Mass Sender v2.1.3

## Русский

### Вход по QR-коду
- С января 2026 года Telegram иногда не доставляет коды входа сторонним программам: сообщает, что код отправлен, но код не приходит ни в Telegram, ни по SMS, ни на почту. Это происходит на стороне Telegram, у всех сторонних клиентов.
- Теперь аккаунт можно подключить **по QR-коду**, без кода подтверждения. Кнопка **«Войти по QR-коду»** есть в окне «Подключение Telegram» и на экране ввода кода. На телефоне, где аккаунт уже открыт: Telegram > **Настройки > Устройства > Подключить устройство**, и наведите камеру на код. Код обновляется сам каждые полминуты. Если на аккаунте есть пароль двухфакторной аутентификации, программа спросит его, как и при входе по коду.
- Если отсканировать код в другом аккаунте, программа сохранит тот, который вы отсканировали. Если этот аккаунт уже добавлен, программа об этом скажет и не создаст второй.

### Куда ушёл код
- Раньше окно всегда писало «Введите код из Telegram», даже если Telegram отправил код по SMS или на почту. Теперь над полем написано, куда на самом деле ушёл код: в чат «Telegram» на другом устройстве, по SMS, звонком, на почту или через Fragment.
- Если Telegram предлагает другой способ, появляется кнопка **«Отправить код ещё раз»**. Она становится активной через то время, которое назначил Telegram.
- Если Telegram требует то, чего сторонняя программа сделать не может (привязать почту для входа или пройти проверку официального приложения), окно сразу предлагает войти по QR-коду.
- Отдельные сообщения для частых ошибок: «Слишком много попыток входа с этим номером» и «Telegram заблокировал этот номер».

### Исправления
- **«Не удалось подключиться: no running event loop».** Ошибка появлялась, если при первом запуске нажать «Начать» в приветственном окне и подключать аккаунт оттуда. Приветственное окно открывалось раньше, чем программа была готова к работе с сетью. Исправлено.
- **Аккаунт после неудачного входа появлялся только после перезапуска.** Программа сохраняет аккаунт, как только запрашивает код, но обновляла список только после успешного входа. Теперь список обновляется при любом закрытии окна входа. Незавершённый вход виден со статусом «Требуется повторная авторизация»: его можно удалить или подключить заново.

### Приватность
- Номер телефона больше не пишется в журнал программы целиком, только код страны и две последние цифры. Журнал попадает в диагностический пакет (ZIP), а в остальной диагностике номера нет с версии 2.1.1.

## English

### Sign in with a QR code
- Since January 2026 Telegram sometimes doesn't deliver sign-in codes to third-party programs: it reports the code as sent, but nothing arrives in Telegram, by SMS or by email. This happens on Telegram's side, for every third-party client.
- You can now connect an account **with a QR code**, no confirmation code needed. The **Sign in with QR code** button is in the "Connect Telegram" window and on the code screen. On a phone where the account is already open: Telegram > **Settings > Devices > Link Desktop Device**, and point the camera at the code. The code refreshes by itself every half minute. If the account has a two-factor password, the program asks for it, as with a code.
- If you scan the code in a different account, the program keeps the account you actually scanned. If that account is already added, the program says so and doesn't create a second one.

### Where the code went
- The window used to always say "Enter the code from Telegram", even when Telegram had sent it by SMS or email. It now says above the field where the code actually went: the "Telegram" chat on another device, SMS, a call, email or Fragment.
- When Telegram offers another way, a **Resend code** button appears. It becomes active after the wait Telegram sets.
- When Telegram asks for something a third-party program can't do (set up a login email, or pass a check only official apps can), the window points to QR sign-in straight away.
- Their own messages for two common errors: "Too many sign-in attempts for this number" and "Telegram has banned this phone number".

### Fixes
- **"Couldn't connect: no running event loop".** It happened when, on first launch, you pressed "Get Started" in the welcome window and connected an account from there. The welcome window opened before the program was ready to use the network. Fixed.
- **An account from a failed sign-in appeared only after a restart.** The program saves the account as soon as it requests the code, but refreshed the list only after a successful sign-in. The list now refreshes however the sign-in window closes. An unfinished sign-in shows as "Re-authorization required": delete it or connect it again.

### Privacy
- The phone number is no longer written to the program's log in full, only the country code and the last two digits. The log goes into the diagnostic bundle (ZIP); the rest of Diagnostics has had no phone number since 2.1.1.
