# TelegramMassSender v2.1.0 — release notes (draft)

> Draft. Not published, no tag yet; `APP_VERSION` is still 2.0.1. Fill in the download link and the date at release time.

## English

### Groups, supergroups and channels as recipients
- Send to groups, supergroups (forums: to the "General" topic) and channels **the account is already a member of and allowed to post in** — by `@username` / `t.me/username`, chat ID (`-100…` / `-…`), `t.me/c/…` link, or an invite link the account has already joined (`t.me/+…`, only checked, never joined).
- People and chats can be mixed in one list. Each chat is checked against its permissions before sending (admin rights for channels; member restrictions, media rights and slow mode for groups). Telegram's errors are shown as clear reasons.
- Slow mode fails only that chat ("wait N sec") and the campaign goes on; FloodWait still pauses the campaign as before.
- `{name}` becomes the chat title for a chat (a CSV name still wins). Reports have a type column; Retry never re-sends to a chat already delivered to and resumes a partly delivered message.

### New interface
- A calmer, consistent design in both themes: one token-based theme system, Inter, Lucide icons, a dark Windows title bar in the dark theme, a collapsible sidebar, a two-column Campaign page with a chat-style preview and a launch panel that turns into live progress, a Results table, toasts for quick confirmations, visible keyboard focus and a logical Tab order. Fits a 1366×768 screen at 125 %.

### Picking recipients from your dialogs
- **From my chats…** (Campaign page and Campaign Wizard) shows every dialog of the active account — people, bots, groups, supergroups, forums, channels — newest first, with type filters, Telegram folders (including shared folders), an archive toggle and search.
- Dialogs the account can't write to are greyed out with the reason; recipients already in the list are marked and not added twice.
- People without a @username are added by ID and found through the account's dialogs at send time.
- The list is read once per session per account; **Refresh** reads it again. Nothing is joined and no avatars are downloaded.

### Protection against an accidental mass send
- With more recipients than the **Large campaign** threshold (Settings → Sending, default 50, minimum 10), a separate confirmation always appears before starting — even with "Confirm before starting a campaign" off. It shows how many people, bots and chats will receive the message; Cancel is the default.

### Changes in behaviour
- **Retry** now also asks for confirmation when "Confirm before starting a campaign" is on, and always above the large-campaign threshold.
- **From my chats…** now lists people and bots too, and shows chats the account can't write to (greyed out) instead of hiding them.
- A person given by numeric ID who isn't known to the session is now looked up in the account's dialogs instead of failing as "not found".
- The dialog list is kept for the session; press **Refresh** in the picker to see chats joined since.
- Demo Mode has people, bots, an archive, folders and chats without rights to try the picker on.

### Known limitations
- Posting into a specific forum topic isn't supported (always "General").
- Tested against a mock Telegram client and Demo Mode; please check against your own account before relying on it.

## Русский

### Группы, супергруппы и каналы в получателях
- Отправка в группы, супергруппы (форумы — в тему «General») и каналы, где аккаунт **уже состоит и имеет право писать**: по `@username` / `t.me/username`, ID чата (`-100…` / `-…`), ссылке `t.me/c/…` или ссылке-приглашению, по которой аккаунт уже вступил (`t.me/+…` — только проверяется, программа сама никогда не вступает).
- Люди и чаты могут быть в одном списке. Права в каждом чате проверяются до отправки (права администратора в канале; ограничения участников, медиа и медленный режим в группах), ошибки Telegram показываются понятными причинами.
- Медленный режим проваливает только этот чат («подождите N сек.»), рассылка идёт дальше; FloodWait по-прежнему ставит рассылку на паузу.
- `{name}` для чата — его название (имя из CSV по-прежнему важнее). В отчётах есть тип получателя; «Повтор» не отправляет повторно в чат, куда уже доставлено, и продолжает частично доставленное сообщение.

### Новый интерфейс
- Спокойный единый дизайн в обеих темах: одна система токенов, шрифт Inter, иконки Lucide, тёмный заголовок окна Windows в тёмной теме, сворачиваемое меню, страница «Кампания» в две колонки с предпросмотром в виде сообщения и панелью запуска, которая превращается в ход рассылки, таблица результатов, всплывающие уведомления, видимый фокус клавиатуры и логичный порядок Tab. Помещается на экран 1366×768 при масштабе 125 %.

### Выбор получателей из своих диалогов
- **«Из моих чатов…»** (страница «Кампания» и Мастер кампании) показывает все диалоги активного аккаунта — людей, ботов, группы, супергруппы, форумы и каналы — сверху свежие; фильтр по типу, папки Telegram (включая общие), переключатель архива и поиск.
- Диалоги, куда писать нельзя, приглушены, причина — в подсказке; получатели, которые уже есть в списке, помечены и второй раз не добавляются.
- Люди без @username добавляются по ID и при отправке находятся через список диалогов аккаунта.
- Список загружается один раз за сеанс для аккаунта; кнопка **«Обновить»** загружает его заново. Программа никуда не вступает и не скачивает аватарки.

### Защита от случайной большой рассылки
- Если получателей больше порога **«Большая рассылка»** (Настройки → Отправка, по умолчанию 50, не меньше 10), перед стартом всегда показывается отдельное подтверждение — даже при выключенном «Подтверждать запуск рассылки». В нём видно, сколько людей, ботов и чатов получат сообщение; по умолчанию выбрана «Отмена».

### Изменения поведения
- **«Повторить ошибки»** теперь тоже спрашивает подтверждение, если включено «Подтверждать запуск рассылки», и всегда — выше порога большой рассылки.
- **«Из моих чатов…»** показывает и людей с ботами, а чаты, куда писать нельзя, — приглушёнными, а не скрывает их.
- Человек, указанный числовым ID и неизвестный сессии, теперь ищется в диалогах аккаунта, а не сразу получает «не найден».
- Список диалогов хранится в течение сеанса; чтобы увидеть чаты, в которые вы вступили позже, нажмите **«Обновить»** в окне выбора.
- В демо-режиме появились люди, боты, архив, папки и чаты без прав — на них можно попробовать окно выбора.

### Известные ограничения
- Отправка в конкретную тему форума не поддерживается (всегда «General»).
- Проверено на мок-клиенте Telegram и в демо-режиме; перед использованием проверьте на своём аккаунте.
